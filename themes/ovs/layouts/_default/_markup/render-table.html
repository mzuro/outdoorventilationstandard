Markdown tables in page prose (research papers have up to 36 apiece) were rendering bare: no wrapper, so a wide table pushed the whole document out to the right at narrow viewports (scrollWidth > clientWidth). This hook wraps every markdown-rendered table in .ovs-table-wrap (the same overflow-x:auto utility used by the homepage/research-list .ovs-table — see base.css) so the TABLE scrolls internally instead of the page.
