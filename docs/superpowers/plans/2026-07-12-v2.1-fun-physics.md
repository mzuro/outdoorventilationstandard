## Global Constraints (inherit ALL v2 constraints, plus)

- Physics readouts must not change: 39/39 tests stay green untouched; every readout still equals its physics-module computation exactly.
- The smoke is a VISUALIZATION of the same physics (plumeRadius / deflection / captureFraction / WIND_COUPLING) — never a separate model that could disagree with readouts.
- Escaping smoke renders ember-orange (Field Guide trick); captured smoke fades into the hood. Colors via new tokens `--smoke`, `--smoke-escape` (both themes, contrast-checked as non-text graphics).
- `prefers-reduced-motion`: NO particle animation — render a static translucent plume-density silhouette instead; all new interactions still functional.
- Direct manipulation NEVER replaces controls: sliders/segments stay, stay keyboard-operable; drag targets get `role="slider"` semantics or delegate to the real input; width drags snap to 6"; hit targets ≥44px.
- Performance gates hold: Lighthouse Perf ≥95 on instrument pages, CLS = 0 (space already reserved), main-thread frame budget — cap particles (≤120 live), use one rAF, pause emitters when figure off-viewport (IntersectionObserver) and when `document.hidden`.
- Verdict stamps use standards voice: PASS / MARGINAL / FAIL + a real clause reference (e.g. "per OVS-H1 §2.4 / RB-005"); thresholds derived from physics (default: capture ≥0.85 PASS, 0.60–0.85 MARGINAL, <0.60 FAIL; CFM instrument: recommended-met basis; document per-instrument in code).
- Engine additions are OPT-IN spec keys — instruments not yet migrated keep working unchanged.
